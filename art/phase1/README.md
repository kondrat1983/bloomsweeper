# Phase 1: style directions and creatures

Canvas (private, Claude Design): https://claude.ai/artifact/Hzwen9jf48WH8totQzWxiJ

- Directions A (clean pen), B (living ink), C (etched botanical) of the Find screen.
- **Chosen by Kondrat (2026-11-02): A with the living line of B.** Ground texture: stipple and short
  grass dashes in the gaps, mood from Hidden Folks (feel only, nothing copied).
- `creatures/`: original creature line art in the package format (viewBox centred, `#art` group,
  44 pt `#hit` circle): bee (walking, flying), rabbit (sitting, alert), fox (sitting, asleep),
  decorative moth (no stripes, no face), revealed fox before and after painting.
- `tools/`: the scripts that drew the style frames and creatures (`creatures.mjs` holds the
  creature paths). Run from this folder with Node 22.

These are style frames, not final page art: cells here follow the cell rules loosely.
